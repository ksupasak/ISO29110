The repository's own WP07 template under `templates-default/` carries program tags (`{topic}`, `{#attendees}`); this skill uses the untagged copy named above.

## Not from audio
- เลขที่บันทึก (MR-<พ.ศ.>-nn) — ask the user
- รหัสโครงการ — ask the user unless given as project context
- บันทึกโดย, ผู้จัดประชุม — ask the user
- Page header: MR No. = เลขที่บันทึก, Version 1.0, Date = meeting date
- ผู้อนุมัติ, สถานะเอกสาร (Draft / Approved) — leave as Draft; never mark Approved
- ช่องลงชื่อท้ายเอกสาร — leave as in template

## Sections

### หัวเอกสาร (header table)
- where: first table — rows โครงการ, รหัสโครงการ, หัวข้อการประชุม, วันที่ / เวลา, สถานที่, บันทึกโดย, ผู้จัดประชุม, สถานะเอกสาร
- needs: project name, meeting topic (include the meeting ordinal if said), date, start–end time, place
- required: yes
- form: fields(โครงการ, หัวข้อการประชุม, วันที่, เวลาเริ่ม–เลิก, สถานที่)
- hints: "วันนี้วันที่", "ประชุมครั้งที่", "เริ่มประชุมเวลา", "เลิกประชุมเวลา", "ประชุมผ่าน", "ที่ห้อง"
- ask: การประชุมนี้จัดที่ไหน (ห้องประชุมหรือออนไลน์) และเริ่ม–เลิกกี่โมง

### 1. Purpose of meeting / วัตถุประสงค์การประชุม
- where: row 1 of the main table
- needs: why the meeting was held, one to three points
- required: yes
- form: paragraph
- hints: "วัตถุประสงค์", "วันนี้เราจะคุยเรื่อง", "วาระ"
- ask: วัตถุประสงค์ของการประชุมครั้งนี้คืออะไร

### 2. Name of attendees / ชื่อผู้เข้าร่วมประชุม
- where: row 2 — inner table, plus the line ผู้ไม่ได้เข้าร่วม
- needs: every person present with role and organisation; who was absent
- required: yes
- form: table(ลำดับ, ชื่อ-สกุล, ตำแหน่ง, หน่วยงาน, บทบาทในโครงการ)
- hints: "ผู้เข้าประชุม", "วันนี้มี", "ขอแนะนำ", "ลาประชุม", "ติดภารกิจ"; also collect every name that speaks or is addressed
- ask: ขอรายชื่อผู้เข้าร่วมประชุมพร้อมชื่อ-สกุลเต็ม ตำแหน่ง และหน่วยงาน และมีใครไม่ได้เข้าร่วมบ้าง
- note: names are the most often mis-heard words. A recording usually gives first names only; full name and organisation are almost always a question.

### 3. Date, place held / วันที่และสถานที่จัดประชุม
- where: row 3
- needs: same date, time and place as the header
- required: yes
- form: fields(วันที่, เวลา, สถานที่)
- hints: as the header
- ask: (covered by the header question)

### 4. Reference to previous minutes / อ้างอิงบันทึกการประชุมครั้งก่อน
- where: row 4
- needs: number or date of the previous meeting record; "ไม่มี" for a first meeting
- required: yes
- form: paragraph
- hints: "จากการประชุมครั้งก่อน", "ครั้งที่แล้ว", "ตามที่คุยไว้เมื่อ"
- ask: การประชุมครั้งก่อนคือบันทึกเลขที่ใด หรือครั้งนี้เป็นครั้งแรก

### 5. What was accomplished / สิ่งที่ดำเนินการแล้วเสร็จ
- where: row 5
- needs: work reported as finished or progress reported, with figures said (percent, days late)
- required: yes
- form: bullets
- hints: "เสร็จแล้ว", "คืบหน้า", "ทำไปได้", "ช้ากว่าแผน", "รายงานว่า"
- ask: นับจากการประชุมครั้งก่อน มีงานใดเสร็จแล้วหรือคืบหน้าไปเท่าใด

### 6. Related issues / ประเด็นที่เกี่ยวข้อง
- where: row 6
- needs: topics discussed, problems raised, new requests — things talked about that are neither a decision nor an open action
- required: no
- form: bullets
- hints: "มีปัญหา", "ลูกค้าขอ", "ข้อสังเกต", "ความเสี่ยง"
- ask: มีประเด็น ปัญหา หรือข้อเสนอใดที่หยิบยกขึ้นมาในที่ประชุมอีกหรือไม่

### 7. Any open issues / ประเด็นค้าง
- where: row 7 — inner table
- needs: each unresolved item or action with its owner and due date
- required: yes
- form: table(ลำดับ, ประเด็นค้าง, ผู้รับผิดชอบ, กำหนดชี้แจง, สถานะ) — กำหนดชี้แจง is the due date
- hints: "งานที่ต้องทำต่อ", "ฝากคุณ…", "ยังไม่ได้ข้อสรุป", "ภายในวันที่", "จะไปดูมา"
- ask: ประเด็น «…» ใครเป็นผู้รับผิดชอบและกำหนดเสร็จเมื่อใด (ask once per item that lacks an owner or a due date; if there are no open issues at all, ask the user to confirm that)
- note: status is ค้าง for everything newly recorded.

### 8. Agreements / ข้อตกลง
- where: row 8
- needs: decisions the meeting made, each as one sentence that stands on its own
- required: yes
- form: bullets
- hints: "ที่ประชุมมีมติ", "ตกลงว่า", "สรุปว่า", "เห็นชอบ", "อนุมัติ"
- ask: ที่ประชุมมีมติหรือข้อตกลงอะไรบ้าง

### 9. Next meeting, if any / การประชุมครั้งต่อไป
- where: row 9
- needs: topic, date, time, place of the next meeting
- required: no
- form: fields(หัวข้อ, วันที่, เวลา, สถานที่)
- hints: "ครั้งหน้า", "นัดครั้งต่อไป", "เจอกันอีกที"
- ask: มีการนัดประชุมครั้งต่อไปหรือไม่ ถ้ามี วันเวลาและสถานที่ใด
- note: nothing said about a next meeting → write "ยังไม่ได้กำหนด" (a true statement about the meeting, not a filler).
